# dsh-prompt-polish：在 DSH 输入框里润色提示词

在 DSH 的对话输入框里写下你的需求，点一下旁边的 ✨ 润色，几秒钟内拿到一份结构完整的提示词——角色、目标、背景、约束、输出格式，一样不缺。结果默认只写回输入框，发不发由你。

润色引擎移植自 [linshenkx/prompt-optimizer](https://github.com/linshenkx/prompt-optimizer)（AGPL-3.0），模板逐字保留；按钮、面板、历史与对比功能由本仓库实现。

## 为什么需要它

你清楚想让模型做什么，但草稿里往往只有一句话：没角色、没背景、没输出要求。模型答得不算错，但不是你要的——于是你追加一句"再详细点"，它换一副面孔，你还是没拿到想要的东西。问题不在模型，在于任务没说全。

手写一份完整提示词并不难，难在每次都写。这个按钮替你写：它把你的原话连同任务必备的结构一起交给模型，产出的不是华丽辞藻，而是一份你可直接执行的任务书（下面有两个真实对照）。

## 一分钟上手

1. 在输入框写下你的需求，长短随意。
2. 点输入框旁的 ✨ 润色。
3. 面板里流式看到优化稿，三个去处任选：**替换草稿**（写回输入框，不发，你过目后自己按回车——默认推荐）、**发送草稿**（写回并直接发）、**复制草稿**（只进剪贴板）。
4. 不满意就在面板里切到「迭代优化」，写一句"再简短些""加个输出示例"，在上一版基础上继续改。

## 两个真实例子：润色前后，模型拿到的任务差在哪

**例一：一句口语反馈 → 七条可执行要求。** 输入是"你不要僵硬，实际都是以具体内容为准的。你的目的在于梳理该章节的内容，以思维导图的形式呈现。"——"不要僵硬"是态度不是标准，模型只能猜。润色后模型拿到的是七条编号要求：以你给的章节内容为唯一依据、结构按内容定、一级分支 3—7 个不凑数、下级按实际逻辑展开、节点保留原文术语不增不漏、用 Markdown 嵌套列表输出、多种梳理时选最贴合原文的一种。原话里的每个担心，都落成了一条可核查的要求。

**例二：一句"帮我看看" → 一份评审任务书。** 输入是"我是想让你从产品经理的角度，看看我们这个作品设计的咋样，还有什么需要改进的"——只给了角色，没给评审材料、标准和产出形式。润色后模型拿到的是：先列清单向你要作品信息（名称/用户/痛点/流程/材料），把"看看"锁定成五个评审维度（用户与痛点、功能与场景、流程与上手、同类对比、可行性与价值），规定产出顺序（整体评价 → 按高中低优先级列建议，每条带理由和预期效果 → 材料不足先开口要，不凭空假设）。泛泛而谈的出口被一条条堵上了。

两个例子是同一件事：**润色补的不是字数，是模型无法从你的原话里读出的前提。**

## 它替你管什么

- **结果去向**：复制（只进剪贴板）、替换草稿（写回不发）、发送草稿（写回并发送），三个动作边界清楚。
- **模式选择**：面板顶部的轴决定用哪套模板——系统提示词（你在写 AI 的规则）、用户提示词（你在要活儿）、迭代优化（在上一版上改）。
- **成本可见**：每次结果显示模型、耗时、字数和 token（"本次 120 输入 + 45 输出 = 165 tokens"）；模型没上报就写"未提供"，绝不显示假 0。
- **本机历史（授权制）**：首次生成后先问你——记录只存这台设备，可随时清空。开启后每次润色存为一个版本，在旧版本上迭代会自动串成链；可回看当时的输入和结果、复制、写回、删单条、删整链、清空全部。选"不保存"就一条不存，也不再询问。
- **对比版本链**：原稿｜所选版本｜最新版本 三列并排，附本机结构分析（行数增删、目标/背景/约束/输出格式的覆盖变化），不额外调用模型。
- **变量提取**：让模型找出结果里可参数化的片段，替换成 \`{{变量}}\` 占位，写回即得模板。

## 代价与边界

- **每次润色 = 一次模型调用**，按 token 计费的环境会真实产生开销（典型几百 token，面板可见）。打开面板、浏览历史不产生调用。
- **结果质量取决于模板与模型**：它补结构，不会替你补你忘了写的事实。
- **等待由模型速度决定**：面板如实显示耗时，不假装秒出；嫌慢可在面板里换个模型。
- **已写好的提示词不需要它**：角色、约束、格式俱全的草稿，润色收益有限。

## 隐私

历史（如果你开启）只写在你自己机器的浏览器存储里，不上传、无遥测、无账号。删除是真删除。关闭后可随时在历史页重新开启。

## 安装

需要 DSH（desktop 或 web profile）和 Node.js 18+。

```powershell
git clone https://github.com/benrong2048-boop/dsh-prompt-polish.git
cd dsh-prompt-polish
pwsh -File install-plugin.ps1 -ProfileName desktop   # 或 -ProfileName web
```

脚本把包装进 `%USERPROFILE%\.dsh\profiles\<profile>\node_modules\`，做语法检查，并把插件行写进该 profile 的 `cordis.patch.yml`（脚本会打印写入了什么）。之后**完整重启 DSH**——桌面应用没有绑定刷新键，Ctrl+R 无效。

手动安装：把本目录复制到上面的 node_modules 路径，再在 cordis.patch.yml 里加：

```yaml
- insert:
    - id: prompt-polish
      name: "@mimo-ai/dsh-client-ui-prompt-polish"
```

卸载：删掉包目录和上面那段 insert，重启 DSH。
